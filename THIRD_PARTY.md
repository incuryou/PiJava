Unifont's exact pinned input hash is `f9c8c7802453f47be02677176aeac2342ee96d354fad7a26cedcce48e68e1d9f`. Its original dual-license text is retained in full, including the GPL font exception, OFL 1.1 and public-domain jiskan16 statement. WenQuanYi's full BDF attribution comments and all original license files remain in this repository.

The inherited `cjk16.bin` non-CJK portion was not completely regenerated. Read-only comparison establishes correspondence for 21,422 of 21,425 records with the pinned Unifont input, including exact bitmaps, the historical row shift, halfwidth expansion and doubled ASCII/Latin or punctuation aliases. Three inherited glyphs (U+FF02, U+FF06 and U+FFE6) do not match the checked transformations; their exact historical input/version remains unrecorded. This is a provenance limitation, not a new license grant. The source snapshot preserves all bitmap bytes.

## Artwork and fixture provenance

- `assets/icon.svg` and its PNG/JPEG renders are described in the baseline's `docs/RELEASE-0.1.83.md` as project-created red/white phone artwork without manufacturer logo graphics.
- `assets/phone-skins/phone-{black,blue,ivory}.png` and `romfs/skins/phone-*.skin` descend from the existing phone concept artwork. Baseline `docs/RELEASE-0.1.85.md` records use of image generation to remove the game image from the concept; `assets/phone-skins/README.md` and `packed-assets.json` preserve packing geometry and input/output hashes. This records the production process, not a claim that every reference image was independently authored by this project.
- The newer `assets/phone-skins/controller-*.png` and `assets/keymap/pro-controller.png` were prepared using built-in image generation from user-provided reference images to remove labels and extract transparent artwork. Their packed derivatives are `romfs/skins/controller-*.skin` and `romfs/ui/pro-controller.rgba`; source/output hashes and geometry remain in the adjacent JSON files. No ownership of depicted hardware designs or trademarks is claimed.
- `assets/keymap/public-phone.svg`, `assets/keymap/public-phone.png` and `romfs/ui/nokia5300.rgba` are the public edition's project-created, unbranded generic phone diagram, licensed GPL-3.0-or-later. `tools/generate_public_phone.py` reconstructs the artwork from native shapes and project-drawn pixel numerals/symbols without external image/font input. The historical `nokia5300.rgba` filename is retained for runtime compatibility; it does not identify an official Nokia image. The previous reference illustration, whose upstream license was not recorded, is excluded from this public edition.
- `tests/fixtures/jpeg/` is documented in its README as synthetic Pillow/libjpeg fixtures, without game images. Example/test Java sources are provided separately from user games.

## External build dependencies and release scope

libnx ([ISC-style license](licenses/libnx.txt)) and deko3d ([license](licenses/deko3d.txt)) are external Switch SDK dependencies. The SDK, Nintendo system font bytes, keys and commercial game JARs are not distributed here. The presence of a test API header is not distribution of the complete SDK.

The initial public release scope is this source repository, without NRO/NSP/desktop binaries or codec libraries. [Historical dependency notes](licenses/DEPENDENCIES-0.2.36.md) remain verbatim; their “excluded fonts” paragraph describes that old archive, whereas this repository includes the font inputs and derived resources listed above. Those notes report that the recovered Switch FFmpeg library package is GPL-configured. This repository must not be described as containing only LGPL FFmpeg material or as the complete corresponding source for a statically linked FFmpeg binary. A public binary release needs a separate review of the exact library configuration, recipes, dependencies, notices and corresponding-source obligations. See [FFmpeg's official legal page](https://ffmpeg.org/legal.html).

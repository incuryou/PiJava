# Pi Java 模拟器 · Fit41-menu7

从上次公开发布的 Fit30 升级到 Fit41-menu7，包含以下新增功能及改进。

## 游戏库与操作

- 主菜单每页显示 10 款游戏，提供“收藏列表 / 全部游戏”，按 Y 切换；收藏列表不按新收藏时间置顶。
- 在主菜单按 − 收藏或取消收藏当前游戏；全部游戏列表显示收藏标记。
- 更多设置提供游戏搜索、中文重命名、存档继承、删除游戏和删除即时存档；支持长按上下连续循环。搜索后按 B 可清空搜索，恢复当前列表。
- 自动读取游戏内部名称并缓存，手动重命名优先；名称变更不修改 JAR 文件名、游戏内容或存档身份。
- 调整更多设置的选项位置、宽度和留白，统一 Y 与 − 的提示间距。

## 游戏内功能

- L3 打开游戏内菜单，使用 L / R 切换存档与退出、按键映射、内存修改页面。
- 内存修改支持整数首次搜索、多轮筛选和候选值修改；可切换整数类型、清空候选。
- 支持系统键盘进行搜索及重命名；标准 MIDP 文本输入框也有系统键盘接入，自绘游戏输入框仍需逐游戏验证。

## 兼容性与性能工作

- 补充 Micro3D 的对象、资源解析和软件渲染路径，继续改进 M3G 的场景、相机、灯光及几何处理兼容性。3D 效果和完整流程仍须逐游戏验收。
- 原生图片解码、预处理和画面呈现采用工作任务分工，保留 CPU 回退；Java 游戏线程和绘图调用顺序保持原有语义。
- 扩展等待空转识别，采用保守的短等待余量，减少主线程无效占用；不修改游戏原始等待分支或 Java 局部变量。
- 原生图片预处理与 render-owner 默认开启；M3G CPU worker 和实验性 GPU 3D 路径仍需显式开启。GPU 显示滤镜不等于所有 3D 游戏都已硬件加速。

## 验证范围

- 菜单、收藏、搜索、重命名及旧配置迁移检查通过；包括 5000 项游戏列表的控制器检查。
- 普通中文字库逐字节保留；图像解码及 Java Graphics 回归、光栅差分和滤镜算术检查通过。
- 完整 Switch SDK 构建、NRO / NSP 内容校验及源码重建一致性检查通过。
- 开发阶段五个固定场景在 30 档下的主线程 CPU 用时减少约 31%～76%，绘制约 30 次/秒；部分 P95 间隔仍增大。该数据来自宿主 VM 短测，不是本版 Switch 实机或完整游戏验收，也不保证所有游戏达到 60 FPS。

## 下载与兼容

附件提供独立 NSP、NRO、完整源码及 SHA256 校验文件。Title ID 沿用 `05004A324D450000`，NACP 为 `0.2.114-k7-f41n`。

游戏内 RMS、J2S5 即时存档与既有配置兼容路径保留。跨章节继承复制 RMS，不转换游戏私有存档格式；数值修改不保证适用于所有游戏，操作前请备份存档。

附件不含商业游戏、用户存档、打包密钥或 SDK。主菜单图片是当前源码的原生宿主 UI 预览，不是 Switch 实机截图。

# 使用 Pi Java模拟器

在支持自制软件的 Switch 环境使用 Release 的 NRO 或独立 NSP；不附带游戏、密钥、用户存档和 SDK。把有权使用的游戏放入 `SD:/switch/j2me/games/`。

- 游戏列表：A 正常开始；X 继续本游戏的即时存档；Y 打开跨章节游戏内存档继承。
- L3：打开菜单或返回游戏。映射编辑页保留当前源码的 L/R 切页操作，A 确认、B 返回、X 恢复草稿默认、Y 切换作用域、+ 保存。编辑草稿会实时更新 Pro 预览，保存后生效。
- 手机方向默认映射左摇杆四向；数字 2/4/6/8 不再默认占用左摇杆。已有自定义配置保留。
- 主菜单左右切换游戏列表/选项；确认键选择遮罩或滤镜。未映射的遮罩键留空。编辑页已删除手机参考图，保留手机键网格和 Pro 预览。
- 原画使用 CPU 呈现；双线性、Scale2x、LCD、CRT、ScanlinesDX 自动使用 GPU，并有 CPU 后备路径。Native / 30 / 60 是速度目标，不保证所有游戏产生同样数量的逻辑帧。

## 跨章节游戏内存档继承

先在上一章游戏内保存并退出，选中下一章后按 Y，选择上一章，按 A 查看并再次确认。来源 RMS 不移动、不删除；目标旧目录会备份，再进行整组复制。完成后用 A 新开目标游戏，在游戏内读取继承的数据。

功能不转换游戏私有存档格式，章节之间必须自行兼容；即时存档包含 VM 内存和代码状态，不能跨 JAR 继承。恢复目标导入前的即时存档也可能覆盖新导入的状态。

正常目标备份位于 `SD:/switch/j2me/rms/chapter-backups/<目标JAR的SHA256>/old-N/`。需要手动恢复前先关闭模拟器，并额外备份当前目录。不要清空整个 RMS。中断恢复逻辑不等于 SD 卡突然断电时的物理持久性保证。

## 兼容性与反馈

仅支持当前 J2S5 即时存档；旧格式拒绝读取并保留原文件。不同源码版本、类布局或 JAR 可能导致存档不兼容。

遇到问题请说明游戏版本/哈希、NRO 或 NSP、实机或 Ryujinx、操作步骤及错误文字。提交日志前清理个人信息；无需上传游戏、用户存档或密钥。短时标题画面测试不能替代整关卡与设备验收。

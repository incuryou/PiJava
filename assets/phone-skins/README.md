# 三款完整手机遮罩（0.1.89）

银蓝款使用用户确认的圆角机身预览，黑银金属、复古米灰保留0.1.88制作源。三款机身的上、下、左、右触达1280×720边缘，四角保留原背景。

`tools/pack_phone_skins.py` 使用明确的源图外轮廓与LCD开口坐标，以九区域映射将开口精确对齐 `(400,40,480,640)`。所有坐标采用左上包含、右下不包含；机身单独缩放，游戏画面不参与纹理打包。坐标、制作源SHA-256、发布资源SHA-256及体积记录于 `packed-assets.json`。

PNG与JSON仅供制作，NRO只嵌入三个 `.skin` 文件。0.1.89三款分别121,985 / 75,647 / 86,165字节，共283,797字节（277.15 KiB）。

格式沿用0.1.88：20字节头 `J2SJ`、LE16宽1280/高720、LE32左JPEG长度/右JPEG长度/保留0，随后两个640×720 baseline JPEG。质量80、4:4:4、不渐进。复用现有JPEG解码器，游戏图片1024尺寸上限保持不变。载入后中央窗口强制为精确黑色，避免JPEG压缩误差侵入游戏区域；游戏按原来的整数2倍CPU路径覆盖整个窗口。

只在换款时解码，当前一张RGBA缓存占3.52 MiB；加载检查各JPEG长度不超过512KiB、每半尺寸、终止EOI与文件末尾，失败回退原生绘制。该运行逻辑本轮未改。

普通构建直接打包提供的 `.skin`，不需要Pillow。重新制作运行 `python3 tools/pack_phone_skins.py`（需要Pillow）。`tools/preview_phone_skins.cpp` 通过原生载入/绘制路径输出空窗口预览；可接受一个240×320 RGB P6 PPM作为游戏示例，输出独立预览，不写回遮罩。复现步骤见 `verification/phone89/README.md`。

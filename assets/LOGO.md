# Pi Java logo

`app-logo.png` is the maintainer-supplied Pi Java logo used by the uploaded KeyUI6 build. Its PNG encoding differs from an earlier local copy, while the committed 256x256 JPEG is byte-identical to the selected NRO/NSP icon. `tools/render_icon.py` keeps the complete composition, flattens alpha on white, and creates PNG/JPEG derivatives plus NSP control icon inputs.

This is the application icon; it is separate from the phone illustration removed from the mapping editor. No third-party trademark rights are granted by the source-code license.
